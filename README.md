
# Global Fuel Prices and Taxation Trends
### A Comprehensive Global Analysis

## 1. Project Overview
This project explores global fuel prices and taxation trends across countries and regions over time. It presents fuel-price data through interactive Tableau visualizations and a Tableau Story embedded in a Flask-based website.

## 2. Project Objectives
- Compare gasoline and diesel prices across countries.
- Explore changes in fuel prices over different years.
- Compare fuel prices across regions.
- Understand the role of taxes in pump prices.
- Explore inflation-adjusted fuel prices.
- Present the analysis through an interactive website.

## 3. Tools and Technologies
- **Python:** Runs the web application.
- **Flask:** Connects the website pages to the application.
- **HTML:** Structures the website.
- **CSS:** Styles the website and its layout.
- **Tableau:** Creates charts, the dashboard and the data story.
- **CSV:** Stores the project dataset.

## 4. Dataset
The project uses CSV data containing country-wise and region-wise fuel-price information. Depending on the available records, the dataset includes fields such as country, region, year, gasoline price, diesel price, tax percentage and inflation-adjusted price.

## 5. Data Preparation
The dataset files were organized and combined for analysis. The prepared data was used to compare fuel prices and taxation across countries, regions and years.

## 6. Visualizations and Dashboard
The Tableau dashboard presents comparisons and trends using the visualizations created for the project, such as:
- Country-wise gasoline prices.
- Year-wise fuel-price trends.
- Regional fuel-price comparisons.
- Taxation comparisons.
- Inflation-adjusted fuel-price analysis.


## 7. Tableau Story
The Tableau Story presents the analysis in a sequence of story points to help users explore global fuel-price comparisons, historical trends, regional differences and taxation patterns.

## 8. Website Features
- Project introduction and overview.
- Embedded Tableau dashboard.
- Embedded Tableau Story.
- Styled webpage using HTML and CSS.
- Flask-based local web application.

## 10. How to Run the Website
1. Install Python if it is not already installed.
2. Open a terminal in the project folder.
3. Install Flask:

   py -m pip install flask

4. Start the application:

   py app.py

5. Open a browser and visit:

   http://127.0.0.1:5000/
